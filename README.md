# Radar para .NET

SDK do [Radar](https://radar.oconde.dev) para C# e .NET: erros com a pilha e o código em volta, logs, contexto por requisição, tarefas agendadas e mascaramento de dados sensíveis. Funciona do .NET Framework 3.5 ao .NET 10.

**Documentação: https://radar.oconde.dev/docs/sdk/dotnet/**

| Pacote | Para |
|---|---|
| `Oconde.Radar` | Qualquer app .NET (núcleo, sem dependências) |
| `Oconde.Radar.AspNetCore` | ASP.NET Core 2.1+ |
| `Oconde.Radar.Extensions.Logging` | Microsoft.Extensions.Logging |
| `Oconde.Radar.Serilog` | Serilog |
| `Oconde.Radar.NLog` | NLog |
| `Oconde.Radar.Log4Net` | log4net |
